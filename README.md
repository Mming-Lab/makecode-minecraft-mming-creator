# mming-creator

🌐 **Languages**: English | [日本語](README_ja.md)

A MakeCode extension for Minecraft Education that brings together three Mming Lab extensions:

- **Camera**: camera angles, smooth camera moves with 32 easing styles, fades, camera presets and input control
- **Shapes**: fast 3D shapes (sphere, cylinder, cone, torus, ellipsoid, helix, paraboloid, hyperboloid, cuboid, Bézier curves)
- **Coordinates**: get the positions of a shape as a list, and rotate a position around an origin

## Installation

1. In MakeCode for Minecraft, click **Extensions**.
2. Search for this URL:

   ```
   https://github.com/Mming-Lab/makecode-minecraft-mming-creator
   ```

3. Select **mming-creator** to add it.

## Previous extensions

This extension replaces the following repositories, which are now archived:

- [makecode-minecraft-camera](https://github.com/Mming-Lab/makecode-minecraft-camera)
- [makecode-minecraft-geometry-ext](https://github.com/Mming-Lab/makecode-minecraft-geometry-ext)
- [makecode-minecraft-rotating-position](https://github.com/Mming-Lab/makecode-minecraft-rotating-position)

Remove the old extension from your project before adding this one, because both define the same blocks.
