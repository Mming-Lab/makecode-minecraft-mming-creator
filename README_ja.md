# mming-creator

🌐 **言語**: [English](README.md) | 日本語

Minecraft Education 用の上級者向け MakeCode 拡張機能です。カメラを動かして撮影し、立体図形を値として組み合わせて配置できます。経験者、またはメンターの指導の下で学ぶ人を想定しています。

4 つのカテゴリは、すべてツールボックスの **高度なブロック** の中にあります。

| カテゴリ | できること |
|---|---|
| **カメラ** | 撮影モード、全部もとにもどす、カメラの配置と移動（イージング 32 種類）、周回、経路に沿った移動、視野角、カメラのゆれ、フェード、視点、操作の制限 |
| **形状** | 図形を値として作る（立体、曲面、線と曲線） |
| **配置と加工** | 図形にブロックを置く、図形を加工する（和・差・積・層・外側・内側・ずらす） |
| **座標** | 自分の前の位置、位置の回転、座標リストの移動と回転、図形と座標リストの変換 |

## インストール

1. MakeCode for Minecraft で **拡張機能** をクリックします。
2. 次の URL で検索します。

   ```
   https://github.com/Mming-Lab/makecode-minecraft-mming-creator
   ```

3. **mming-creator** を選んで追加します。

## 図形

図形のブロックは何も置きません。図形を値として返すので、それを使うブロックに渡します。

```
置く ブロック ガラス 図形（球 中心（自分の前の位置 距離 10）半径 5）
```

| グループ | 図形 |
|---|---|
| **立体** | 球、半球、直方体、円柱、角柱、円錐、角錐 |
| **曲面** | トーラス、楕円体、回転放物面、一葉双曲面 |
| **線と曲線** | 線分、円、螺旋、カプセル、ベジェ曲線 |

図形は変数に入れて、置く前に加工できます。加工すると新しい図形が返ります。

| ブロック | 結果 |
|---|---|
| **和** | どちらかの図形に入るセル |
| **差** | もとの図形のうち、引く図形に入らないセル |
| **積** | 両方の図形に入るセル |
| **図形の外側** / **図形の内側** | 図形の表面、または表面より内側のセル |
| **層を取り出す** | 一部の層だけ。層は軸の小さい側から 0 で数えます |
| **図形をずらす** | 別の場所にある同じ図形 |

### 高さによってブロックを変える

**層ごとに置く** は、リストのブロックを軸に沿って順に使います。もっと細かく決めたいときは、**層を取り出す** で層を取り出して、層ごとに別のブロックで置きます。

### 図形と座標リスト

**図形の座標リスト** で図形をリストに、**座標リストから図形を作る** でリストを図形にできるので、図形を「座標」のブロックに通せます。線分・螺旋・ベジェ曲線の座標は通る順に並ぶので、**経路に沿って動かす** の経路に使えます。ほかの図形は格子の順に並びます。何かのまわりを回るときは **まわりを回る** を使ってください。

リストはセル 1 つにつき 1 件を持つので、小さな図形に留めてください。図形を直接置くほうがずっと軽く動きます。

## 知っておくとよいこと

- **内側を空気にする**: **置く** のオプションで内側を空気にします。今あるブロックの上に **外側** を置くより `/fill` の回数が少なくなります。
- **大きな図形は時間がかかります**: 半径 100 の球は `/fill` が約 7,000 回必要です。進捗はホットバーの上に表示されます。**進捗を表示** で消せます。
- **遠い場所**: プレイヤーの周りしか変更できないので、置いている間は `/tickingarea` で読み込みます。`mmingCreator...` という名前のエリアを 1 つ使い、終わると削除します。エリアは 1 つのワールドに 10 個までです。
- **プログラムが途中で止まると**、プレイヤーが動けないままになることがあります。チャットで次のコマンドを実行するか、**全部もとにもどす** ブロックを使ってください。

  ```
  /camera @s clear
  /hud @s reset all
  /inputpermission set @s movement enabled
  /inputpermission set @s camera enabled
  ```

  ティッキングエリアが残ったときは、`/tickingarea list` で探して `/tickingarea remove <名前>` で削除してください。
